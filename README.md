# ⚠️ Deprecated: ParaSpell XCM SDK✨ starter template

> **This template is deprecated and this repository has been archived.** It is no longer maintained and will not receive further updates, bug fixes, or support. Please use [**`paraspell/cli`**](https://github.com/paraspell/cli) to scaffold new XCM API / XCM SDK projects instead.

The [`paraspell/cli`](https://github.com/paraspell/cli) package supersedes this template. It provides an interactive generator that scaffolds a ready-to-run XCM app for React, Vue, or Node.js, with optional Swap, EVM, and Snowbridge extensions, and supports both the XCM API and the XCM SDK.
